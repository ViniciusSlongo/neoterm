# A interface

> A lateral, a conversa, os painéis e as telas.

## Lateral

| O quê | Como |
| --- | --- |
| Abrir agente ou grupo | `↑↓` e `enter` |
| Quem está trabalhando | `●` verde e spinner ao lado do nome |
| Mensagem nova | `•` depois do nome |
| Notas e tarefas abertas | `✎` e `☐2` depois do nome |
| Precisa de você | itens em amarelo; `enter` abre, `x` dispensa |
| Painel, integrações, config | `d`, `i`, `c` |

## Conversa

| O quê | Como |
| --- | --- |
| Enviar | `enter` |
| Nova linha | `shift+enter` |
| Colar imagem | `ctrl+v`, ou cole o caminho do arquivo |
| Inserir caminho de arquivo | `:path` (no fim da frase, insere ali) |
| Rolar | roda do mouse, `pgup`/`pgdn` |
| Selecionar texto | `ctrl+s`, arraste, `cmd+c`, `esc` |
| Copiar a última resposta | `ctrl+y` |
| Chamar agente (grupo) | `@nome` |

Mensagens enviadas enquanto o agente responde vão para a fila e são respondidas em ordem.

## Notas

`ctrl+n` abre as notas do agente, ao lado da conversa.

| O quê | Como |
| --- | --- |
| Criar ou marcar tarefa | `ctrl+t` |
| Deixar aberta em todo agente | `ctrl+p` |
| Voltar à conversa | `ctrl+n` ou `tab` |
| Fechar | `esc` |

Salvam sozinhas em `~/.neoterm/agents/<nome>/notas.txt`. O agente não as vê.

## Telas

| Tela | Abre com | Mostra |
| --- | --- | --- |
| Painel | `d`, `:painel` | motor, máquina, plano, trabalho do dia, agentes |
| Integrações | `i`, `:mcp` | MCPs do Claude Code |
| Config | `c`, `:config` | cor da interface, modelo padrão |
| Processos | `s`, `:processos` | memória e serviços do agente; `x` encerra |
| Rotinas | `r`, `:rotinas` | rotinas da conversa |
| Ajuda | `?`, `:ajuda` | comandos e teclas |

## Formulários

| O quê | Como |
| --- | --- |
| Próximo campo | `tab` |
| Escolher pasta | `espaço`; `→` entra, `←` volta, `esc` fecha a lista |
| Salvar | `ctrl+s` |
| Excluir (na edição) | `ctrl+d` duas vezes |
| Cancelar | `esc` |
