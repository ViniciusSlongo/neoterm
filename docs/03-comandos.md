# Comandos e teclas

> Tudo o que dá para digitar e apertar, numa página.

## Comandos

Digite `:` na conversa: abre o menu dos comandos, que afunila conforme você escreve.

| Tecla | No menu |
| --- | --- |
| `↑↓` | escolhe |
| `enter` | roda |
| `tab` | completa sem rodar |
| `esc` | fecha (o `:` fica como texto) |

Também dá para escrever o comando inteiro, com `:` ou `/` na frente.

| Comando | Apelidos | O que faz |
| --- | --- | --- |
| `:help` | `:?` | comandos e teclas |
| `:notes` | | notas do agente |
| `:path` | | insere o caminho de um arquivo |
| `:open` | `:view` | abre um arquivo para ler (`:open src/app.ts` abre direto) |
| `:processes` | `:ps` | memória e serviços do agente |
| `:edit` | | edita ou exclui o agente ou grupo |
| `:effort` | | mostra ou muda o esforço: `:effort high` (`low`, `medium`, `high`, `xhigh`, `max`, `default`) |
| `:routines` | | rotinas da conversa |
| `:pause` | | pausa rotinas e retornos do agente |
| `:resume` | | volta a rodar |
| `:dashboard` | `:dash` | painel |
| `:mcp` | | integrações |
| `:config` | `:settings` | cor e modelo padrão |

## Conversa

| Tecla | O que faz |
| --- | --- |
| `enter` | envia |
| `shift+enter` | nova linha (ou `option+enter`, `ctrl+j`) |
| `ctrl+n` | notas |
| `ctrl+r` | rotinas |
| `↑↓`, `pgup`/`pgdn` | rolam a conversa |
| `esc` | vai para a lateral |

## Lateral

| Tecla | O que faz |
| --- | --- |
| `enter` | abre |
| `e` | edita |
| `s` | processos |
| `r` | rotinas |
| `p` | pausa ou retoma |
| `n`, `g` | novo agente, novo grupo |
| `d`, `i`, `c` | painel, integrações, config |
| `?` | ajuda |
| `q` | sai |

## Notas

| Tecla | O que faz |
| --- | --- |
| `ctrl+t` | cria ou marca tarefa |
| `ctrl+p` | fixa ao lado |
| `ctrl+n`, `tab` | volta à conversa |
| `esc` | fecha |

## Listas de pastas e arquivos

| Tecla | O que faz |
| --- | --- |
| `↑↓` | anda |
| `→`, `enter` | entra (no `:path`, num arquivo, insere) |
| `←` | volta |
| `espaço` | escolhe |
| `/` | filtra |
| `.` | mostra ocultos |
| `esc` | fecha |

## Arquivo aberto (`:open`)

| Tecla | O que faz |
| --- | --- |
| `↑↓`, `pgup`/`pgdn` | rolam |
| `←→` | rolam de lado |
| `g`, `G` | começo, fim |
| `/` | busca; `n` próxima, `N` anterior |
| `esc` | fecha |

## Outras telas

| Tela | Teclas |
| --- | --- |
| Rotinas | `n` nova, `espaço` liga/desliga, `x` roda agora, `d d` apaga |
| Processos | `x` encerra, `X` encerra todos, `enter` comando inteiro |
| Config | `↑↓` prévia da cor, `enter` salva, `←→` modelo |
| Formulários | `tab`, `ctrl+s` salva, `ctrl+d ctrl+d` exclui, `esc` cancela |
